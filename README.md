# Student Performance Tracker

A terminal-based Python app to track and manage student grades.
Built this as my first independent project — wanted to go beyond 
classroom exercises and actually build something functional from scratch.

## What it does
- Add students with their letter grades
- View a complete roster
- Case-insensitive search for quick lookup
- Leaderboard sorting using a modified bubble sort algorithm
  (S > A > B > C > D > F)

## What I learned
- Implementing and modifying a sorting algorithm for a real use case
- Structuring a CLI app with clean user flow
- Working with Python lists and string handling

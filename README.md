# Student Performance Tracker

A terminal-based Python application designed to track and manage student grades. This project features a custom grade-weight sorting system using a modified bubble sort algorithm.

## 🚀 Features
* **Add Students:** Save student names alongside their letter grades.
* **View Students:** View a complete roster of all currently added students.
* **Search:** Case-insensitive search to quickly find a specific student's record.
* **Leaderboard Sort:** Sorts the student list based on grade weights ($S > A > B > C > D > F$).
